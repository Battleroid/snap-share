Restoring a snapshot

Snapshots run nightly at 03:00 and are pruned after thirty days. Pick one from the snapshot list, then mount it read-only before copying anything back. See restic.net for flags.

restic mount --repo /mnt/backup /mnt/restore
Never restore over a running database. Stop the container first.

Press ⌘ K to search. Retention is 30 days unless pinned.
