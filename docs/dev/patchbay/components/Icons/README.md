Icons are a 47-glyph, 24px, 1.75px-stroke set in two cuts: round caps and circular frames (soft), square caps and square frames (hard).

- Use: `<span class="pb-icon pb-icon--NAME"></span>`. It paints in `currentColor` and swaps cut with the nearest `data-edge`. Sizes: inherits 1.25em, or `pb-icon--16/20/24`.
- Names: `status-ok, status-warn, status-down, status-info, status-unknown, status-paused, status-maint, link-external, link-internal, link, copy, download, upload, server, database, folder, file, network, cloud, lock, unlock, key, terminal, search, plus, close, check, refresh, settings, chevron-right, chevron-down, clock, trash, power, activity, calendar, eye, eye-off, minus, more, sort, arrow-up, arrow-down, filter, menu, bell, inbox`.
- SVG files of both cuts are in the Icons Soft and Icons Hard asset groups.
- Icon-only buttons need an `aria-label`. Status icons always sit next to a word.
