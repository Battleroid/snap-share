DropZone accepts files by drag or browse and lists uploads under it.

- Consumer provides: `<label class="pb-drop">` with a hidden `<input type="file">`, `.pb-drop__icon` (`pb-icon--upload`), `.pb-drop__title`, `.pb-drop__hint` (accepted types and size limit, with `<u>browse</u>`).
- State via `data-state`: none = idle, `over` while a drag is over it (swap the icon to `download`, title to "Release to upload N files"), `error` for a rejected drop (say why in the hint).
- Uploads: `.pb-filelist` > `.pb-filerow` (icon, name, `.pb-filerow__meta`), with a `.pb-progress` bar (`--value: 62%`) while sending; swap the icon to `status-ok` in `ok` when done.
- Upload settings: wrap the drop zone in `.pb-dropset[data-dropset]` with a `.pb-dropset__box` above it. The box holds `button.pb-dropset__bar` (chevron, `.pb-dropset__summary`, "Change") and `.pb-dropset__panel` with one `.pb-dropset__row` per setting (label, then a `pb-seg`, `pb-select` or `pb-switch`).
  - The summary line is built from the controls: radios and selects carry `data-sum="expires {v}"`; switches carry `data-sum-on` / `data-sum-off` (leave one empty to say nothing in that state).
  - `data-dropset-reveal="id"` on a switch shows a `.pb-dropset__sub` row (a password field) while it is on.
  - `pbDropSet(el)` wires it (included in `pbInit`): the bar opens and closes the panel, Esc closes it, `[data-dropset-reset]` restores the defaults, `[data-dropset-default]` saves the current settings as the defaults. Fires `change` and `default` with the settings.
  - Keep the panel closed by default: the summary tells people what will happen, and they open it only to change something.
- Compact settings: add `pb-dropset--compact`. The panel becomes a three-column grid of `.pb-dropset__field` (a `.pb-dropset__label` above the control): Expires, Visibility and File names on the first row; Strip photo location, Password and the password field on the second. `pb-dropset__field--switch` is a switch with its label beside it. `data-dropset-enable="id"` on a switch enables that field's inputs instead of revealing it, so the row keeps its shape. Under 560px it drops to two columns with Expires and the password field full width, under 340px to one. The footer spans the full width. `pb-dropset__field--wide` spans two columns when a control needs the room. Pair it with `pb-drop--slim`, a one-line drop zone.
