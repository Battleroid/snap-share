Table tools add the controls people expect on big tables: columns, resizing, density, expandable rows, inline editing, CSV and a sticky first column.

- Markup: `.pb-tablewrap.pb-dt[data-dt][data-name]` with a toolbar (`[data-dt-search]`, `[data-dt-count]`, a `[data-dt-density]` radiogroup `comfortable|compact`, `[data-dt-cols]` with an empty `pb-menu.pb-dt__cols`, `[data-dt-export]`), an empty `pb-tablescroll` and a `<script type="application/json">` of `{columns, rows}`.
- Columns: `{key, label, type: "status"|"tags", num, mono, unit, editable, sticky, width, hidden, wrap, sort: false}`. Rows are objects; a `detail` object adds an expand button that shows it as a DetailList.
- `pbDataTable(el)` renders and sorts; drag a header's right edge (or focus it and use ← →) to resize; double-click or press Enter on an editable cell to edit, Enter saves, Esc cancels; it fires `pb:edit` with `{row, key, value, old}`. Columns can be hidden (the sticky one stays); CSV exports the visible columns and filtered rows and fires `pb:export`.
- `data-density="compact"` on any `pb-dt` tightens rows to 32px. Use compact for dense admin tables, comfortable elsewhere.
- Expanded rows show `detail` as a compact grid of label-over-value pairs (`pb-dl--grid`), at most 720px wide so values stay near their labels.
- Keyboard (`pbGridKeys`): the table is `role=grid` and one tab stop. ←/→ move between cells (and the sort button and resize handle in a header), ↑/↓ to the same column, Home/End to the row's ends, Ctrl+Home/End to the grid's, PageUp/PageDown by ten rows. Enter or F2 edits an editable cell (Enter saves, Esc cancels and focus stays on the cell); Enter on a header sorts.
- Resize: the handle is `span.pb-dt__resize[role=separator][aria-orientation=vertical]` with `aria-valuenow` (px), min 60 and max 800, and a 24 px hit area. On the handle ←/→ resize by 16 px (Shift+←/→ moves on); dragging never selects text. A set width is the column's width, not only a cap (`width`, `min-width` and `max-width` from `--w`). **Changed:** the handle was a button, and editable cells were each a tab stop.
