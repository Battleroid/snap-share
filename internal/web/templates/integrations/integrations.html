ShareX

Add options in Destinations › Custom uploader settings, or edit the .sxcu before opening it. The uploader takes them as body arguments. The text uploader and URL shortener send JSON, so add them as keys beside content or url. URL query parameters are ignored. A password typed into the file is stored in plain text beside the key, so ask for it with {inputbox:…} instead.

{{range $i, $c := $d.OptShareX}}{{template "integrations.command" (dict "id" (printf "opt-sharex-%d" $i) "label" $c.Label "value" $c.Command "lang" "sxcu")}}{{end}}

ShareX runs {select:…} and {inputbox:…} in body arguments only, not in a JSON body. To be asked on each text upload or short link, set the body to FormURLEncoded and move content or url into the arguments.

curl

Multipart and form bodies take options as fields, JSON bodies as keys, and raw bodies (-T, --data-binary) in the query string. A password never goes in the query string: send it in the X-Snap-Password header.
