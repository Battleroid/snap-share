# User-Agent rules for stats.Classify and stats.SummarizeUA.
#
# Format:  action | name | token [& token ...]
#
#   action   preview  chat or social link unfurler: recorded as a "preview"
#                     event with the name ("previewed in Discord"), never as
#                     a view.
#            drop     crawler, scanner, monitor or automation: not recorded.
#   name     display name for the stats panel.
#   token    case-insensitive substring of the User-Agent. With "&", every
#            token must appear.
#
# Rules are tried top to bottom and the first match wins, so a specific rule
# goes above any general rule it overlaps. A User-Agent that matches nothing
# is a person: when unsure, leave a client out. curl, Wget, HTTPie, scripts
# and Go-http-client (the sp CLI, scripts) are people using tools and stay.
#
# Rules kept in code, not here (see classify.go):
#   - no User-Agent at all: preview named "Unknown". Signal and some other
#     apps fetch link previews without one.
#   - HEAD and OPTIONS requests, and browser prefetches (Sec-Purpose,
#     Purpose or X-Moz: prefetch): dropped.
